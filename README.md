# ASOS Financial Analysis Dashboard

## Project Overview

An interactive Streamlit dashboard analysing ASOS plc's FY2024–FY2025 financial performance. It calculates core financial ratios from reported figures, produces an illustrative DCF valuation, and generates a structured AI prompt based on the calculated results for further interpretation.

## Features

- Revenue, profit and revenue growth analysis (FY2024 vs FY2025)
- Key ratios: operating margin, net margin, ROE, current ratio, debt-to-equity
- Illustrative DCF valuation (WACC, 5-year FCF forecast, terminal value, enterprise/equity value, sensitivity table) with user-adjustable assumptions
- AI-assisted commentary workflow using the calculated figures
- Automatically generated AI analysis prompt with a download option
- Interactive dashboard with trend charts and a data sources/assumptions section

## Technologies

- Python, Pandas
- Streamlit
- Git
- GitHub

## Methodology

Company financial data (revenue, profit and balance sheet items) is taken from ASOS plc's FY2024 and FY2025 financial reports. Python and Pandas calculate the core ratios using standard financial formulas. A separate DCF section applies WACC and discounted-cash-flow methodology; cost of equity, cost of debt and terminal growth are user-adjustable assumptions rather than figures derived from ASOS's actual market data (e.g. beta). Net debt is simplified as total reported debt.

## AI Component

The calculated financial ratios are automatically inserted into a structured AI prompt generated by Python. The prompt can be downloaded and manually entered into an AI tool such as Claude or ChatGPT for financial interpretation; the AI does not perform the underlying calculations itself.

## Limitations

- Two years of reported data only
- DCF assumptions (cost of equity, cost of debt, terminal growth) are illustrative and user-set, not derived from ASOS's actual beta or market data
- Net debt is simplified as total reported debt (not adjusted for cash)
- AI commentary is generated interpretation based on calculated figures and is not independently verified financial advice
- Not intended as investment advice

## Future Improvements
