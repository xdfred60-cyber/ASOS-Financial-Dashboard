# ASOS Financial Analysis Dashboard

An interactive financial analysis tool analysing ASOS plc's FY2024 and FY2025 financial performance using Python, Pandas and Streamlit.

## Project Overview

This project was built to apply financial analysis concepts in a practical Python-based application.

The dashboard takes reported ASOS financial data and uses Python to calculate key financial ratios and perform a simplified Discounted Cash Flow (DCF) valuation.

It also generates a structured AI prompt using the calculated financial figures, allowing AI tools to provide additional interpretation without performing the underlying calculations.

## Key Features

* FY2024 and FY2025 financial statement data
* Revenue growth analysis
* Operating margin and net margin calculations
* Return on Equity (ROE)
* Current ratio
* Debt-to-equity ratio
* Year-on-year financial analysis
* Interactive WACC assumptions
* Five-year free cash flow forecast
* Discounted cash flow calculations
* Terminal value calculation
* Enterprise value calculation
* Estimated equity value
* DCF sensitivity analysis
* AI-assisted financial commentary prompt
